# ☁️ Projeto Escola da Nuvem — Grupo 3

Sistema Escolar desenvolvido em Python com foco em lógica de programação, estruturas condicionais, entrada de dados e cálculo de média escolar.

##  Funcionalidades

* Cadastro de alunos
* Entrada de notas
* Cálculo de média
* Verificação de status:

  * ✅ Aprovado
  * ⚠️ Recuperação
  * ❌ Reprovado

##  Tecnologias utilizadas

* Python 3
* Git
* GitHub
* VS Code / PyCharm / Colab

##  Objetivo do projeto

Este projeto foi desenvolvido com objetivo educacional para praticar:

* Lógica de programação
* Estruturas condicionais
* Manipulação de variáveis
* Entrada e saída de dados
* Versionamento com Git e GitHub

## ▶ Como executar

Clone o repositório:

```bash
git clone https://github.com/rodrigoab8/sistema-escolar-python.git
```

Acesse a pasta do projeto:

```bash
cd sistema-escolar-python
```

Execute o programa:

```bash
python Programa.py
```
